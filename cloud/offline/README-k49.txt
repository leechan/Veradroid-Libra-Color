把下面 3 个文件放进 documents（VeraDroid 离线安装包，实验机型：PaperWhite 5、Kindle 入门款 2022 / 2024、Kindle Scribe）

  VeraDroid-Offline.sh     ← 安装程序，书库里显示为“VeraDroid 安装（离线）”
  bootstrap.sh
  veradroid-k49-版本号.tar.gz   （不用解压）

1. USB 连电脑，把上面 3 个文件拷进 Kindle 盘的 documents 文件夹（这份说明拷不拷都行）。
2. 拔掉 USB，在书库里点“VeraDroid 安装（离线）”。屏幕上会显示进度。
3. 装好后安装文件会自动删掉，书库里只留下“VeraDroid 启动”，以后点它进 Android。

这些机型只在模拟器里验证过，安装前请备份。
PaperWhite 6 / Colorsoft 请用 VeraDroid-Offline.zip；PW2 / PW3 / PW4 / Voyage / Oasis 用 VeraDroid-Offline-Legacy.zip。拿错了包，安装器会在屏幕上说该用哪个，什么都不改动。
