# VeraHome 界面重做：照 Kindle 本体（没有对应物的地方照文石）

分支 `feat/ui-kindle`。目标是用户提出的：“整体系统操作包括设置和书库打开书籍的排布，以及下拉状态栏等逻辑都去模仿 kindle 系统本体或者文石的操作系统”。

只模仿**排布和操作逻辑**。图标是我们自己在 `Icons.java` 里用线条画的，文字是自己写的，字体用系统的；
不用亚马逊、文石或其他商业方案的任何图片、图标、字体和原文。

## 不能退步的约束

- 每次换页面只让墨水屏刷一次：没有按下高亮帧、没有动画、不先画一部分再补其余、能同步搭出来的页面不异步补内容。
  实测基线（PW6，VeraHome 0.24.0）：桌面↔设置，手指按下到刷完 381–404 ms，桌面自己只占 28–55 ms（`VeraPerf`）。
- 纯黑白：1 / 2 像素黑线，不用灰色填充、阴影、渐变（灰色在墨水屏上会抖动、留残影）。
- 尺寸都从屏幕宽高和密度算：1272×1696（PW6）、1236×1648（PW5）、1072×1448（KT5 / KT6 / PW3）。列表一页一页翻，不滚动。
- 485 MB 机型：封面位图只留屏幕上用得到的几十张。

## 1. 主页

**Kindle**：最上面一行是时间、Wi-Fi、电量；下面是一条圆角搜索框，右边是商店按钮和三点菜单（菜单里有设置等）[PW][XDA]。
旧的“主页 / 返回 / 设置”图标排在改版时去掉了 [XDA][GR]。底部固定两个标签：主页、书库，中间一个小图标跳到正在读的书 [XDA][PW]。
主页内容第一排是“来自您的图书馆”：最近打开过的书，横向一排封面，封面上有百分比 [PW]；再往下是推荐。

**文石**：底部功能栏 书库 / 商店 / 存储 / 应用 / 设置，默认进书库，哪个标签当首页可以选 [LEAF2]。应用在单独的“应用”标签里。

**我们**：
- 最上面一行小字：左边时间和桌面标题（原来的“桌面标题”设置，键 `name` 不变），右边 Wi-Fi 关闭提示和电量。
  只在换页面和整分钟时更新。以前回到主页 0.8 秒后还要改一次（里面有“可用内存”，每次都变），屏幕角上会再刷一小块，去掉了。
- 顶栏：**回 Kindle**（门 + 箭头）｜**搜索框**｜**快捷设置**（打开下拉面板）｜**菜单**（传书、软件商店、使用统计、全部设置、整屏刷新、回 Kindle、关机）。
  Kindle 没有“回 Kindle”，但我们是跑在 Kindle 里的另一个系统，这是最常用的出口，放在最左边。商店按钮的位置换成快捷设置。
- 底栏：**主页 / 书库**，当前的加粗并在上面压一条粗线。没照搬中间的“当前书”小图标（书库里点书就接着读）。
- 主页内容：只有应用网格（分页，划动或点箭头翻）。Kindle 主页没有应用，推荐位我们没有内容可放，这块地方给应用——这是文石“应用”标签的内容，
  合到主页是因为多数人进来就是为了开微信读书。原来上面还有一块“继续阅读”（大封面、进度、最近四本），用户要求去掉（2026-11-12）：
  书在“书库”里，点书就接着上次读。主页因此也不再读书库的索引，开机更快、占内存更少（见下面“自定义”）。
- 主页和书库是两棵各自完整的控件树（各带一份顶栏和底栏），点底栏只换可见的那棵：标签高亮、顶栏、内容同一帧变。
  书库那棵树在主页闲下来 1.5 秒后预先搭好（这时才第一次读书库索引），第一次点“书库”也只是换一棵树。

### 自定义（壁纸、图标、名字）

- **壁纸**：设置 → 应用与桌面 → 壁纸与图标 → 桌面壁纸“选择”：列出内部存储 `VeraDroid/wallpaper`（最前）、`VeraDroid`、`Pictures`、`Download`、`DCIM`、`Books`、
  Kindle 的 `documents`（`KindleLibrary`）和存储根目录里的图片（jpg / png / webp / bmp / gif，新的在前，最多 200 张），点一张就换。
  传书网页的“主题”页上传的壁纸也一样生效。设了壁纸以后多出三行：壁纸铺法（铺满 / 完整显示 / 原大小，键 `wallmode`）、壁纸深浅（原来的键 `wallpaperdim`）、不用壁纸。
  壁纸只在主页显示，书库和设置保持白底。
- 壁纸只解码一次：按屏幕大小缩好、转灰度、按“深浅”盖白，存成 8 位“墨量”图（ALPHA_8，白纸上按墨量画黑色；PW6 2.0 MB，KT5 1.5 MB，
  原来的 RGB_565 是两倍），处理结果另存在 `.vdhome/state/cache/wall/`，开机直接读回来；原图从不留在内存里。换图、换铺法、换深浅都在设置页里后台先做好。
- **单个应用的图标**：长按应用 → 更换图标… → 同一张图片列表里选一张（裁成正方形、缩到 256 像素存成 PNG）；换过的应用多一项“恢复默认图标”。
  只重画当前这一页（一次刷新）。
- **图标样式**（键 `iconstyle`）：原样 / 黑白描框（转灰度，缩进一圈，外面一个圆角黑框）。
- **重命名**：长按应用 → 重命名…，最多 16 个字，留空恢复原名（键 `label_<包名>`）。搜索也按新名字找。
- 所有图标（自定义的和应用自带的）都画成一张正好格子大小的位图缓存起来，画网格时不再缩放；图标大小、样式、主题不变就一直用。

文件夹约定（传书网页以后可以直接往这里写）：

| 位置（/sdcard = /data/media/0） | 作用 |
|---|---|
| `/sdcard/.vdhome/theme/wallpaper.{jpg,png,webp}` | 当前壁纸。设置里选的图复制到这里；网页“主题”页上传 `wallpaper.*` 也写这里 |
| `/sdcard/.vdhome/theme/icons/<包名>.png` | 当前自定义图标（长按 → 更换图标；网页上传 `icon-<包名>.png`）。“恢复默认图标”删的是这个 |
| `/sdcard/VeraDroid/wallpaper/` | 放图片的地方：选壁纸 / 图标时最先列出这里的图片 |
| `/sdcard/VeraDroid/icons/<包名>.png` | 放进来就替换那个应用的图标（优先级低于 theme/icons） |
| `/sdcard/Icons/<包名>.png` | 老位置，仍然认（优先级最低） |

## 2. 书库

**Kindle**：右上“视图”菜单选 全部 / 收藏夹、网格 / 列表；左上“筛选”（已读 / 未读、类型、已下载），选中的条件显示成可以点掉的小条；
排序：最近、书名、作者、出版日期，可升降序 [PW][MR]。封面视图一页 6 本，列表 4–5 行 [MR]。划动翻页，右边有带箭头的滚动条 [PW]。
长按一本书（或点封面上的三点）出菜单：加入主页、加入收藏夹、转到、在书中搜索、从设备删除等 [PW]。
搜索：边打字边出书名 / 作者匹配 [PW]。“标为已读”“关于本书”这两个菜单项的原文未确认。

**文石**：封面 / 列表切换，右上有搜索、筛选排序、阅读统计；默认按最近阅读时间排 [LEAF2]。

**我们**：
- 顶栏和主页同一条。下面一行工具：左“筛选：全部 / 在读 / 未读 / 已读完”，中间“共 N 本”，右“排序：最近 / 书名 / 作者 / 最近添加”和 封面 / 列表 切换。
  选择用我们自己的对话框弹出（Kindle 是下拉菜单，逻辑一样）。偏好键：`lib_sort`、`lib_filter`、`lib_view`；旧键 `lib_recent` 继续读、继续写。
- 封面视图三列，6 寸屏一页两行六本（和 Kindle 一样），封面右上角黑底白字的百分比，读完显示“已读”；没有封面的书（TXT 等）画成“书名 + 格式”的白底格子。
  列表视图一行一本：小封面、书名、作者 · 格式、右边百分比。
- 翻页：在内容上横划或竖划一段，或点底下的 ‹ 页码 ›。没做 Kindle 右侧的拖动滚动条：拖动要跟手连续刷新，墨水屏上不值得。
- 点一本书**直接进阅读器**，回到上次位置（以前默认每次弹“用哪个阅读器”）。只有用户在长按菜单里把默认阅读器改成“每次询问”才问（键 `reader_default` 不变，缺省值从 ask 改成 builtin）。
  内置阅读器读不了的格式（mobi / azw3 / kfx）交给 KOReader。
- 长按：打开、用 KOReader 打开、标为已读 / 未读完、书籍信息、默认阅读器、删除。没有“加入收藏夹”（我们没有收藏夹）、“在书中搜索”（阅读器还没有搜索）。
- 搜索：点顶栏搜索框，顶栏换成输入框，下面变成结果列表（先列名字匹配的应用，再列书）。输入框不显示闪烁的光标（每 0.5 秒刷一小块），
  平时页面上根本没有输入框（顶栏那个只是按钮），不会自己拿到焦点。
- 数据：书单、书名、作者存一份索引（`libidx`），进程起来同步读入；扫目录永远在后台，结果和手里的一样就什么都不动。
  封面缩略图在磁盘上，翻到哪页同步解码哪页，内存里最多留 18 张（小内存）/ 24 张。

## 3. 下拉面板（快捷操作）

**Kindle**：从顶边下划（阅读时先点一下顶部），一张面板从上面盖下来：一排圆形开关——飞行模式、蓝牙、深色模式、同步、全部设置；
下面亮度滑条（两端 − / +，可以点轨道任意位置），再下面色温滑条和“定时”按钮 [PW][XDA][XDA-W]。再划一下或点箭头收起 [XDA]。
面板里有没有“自动亮度”复选框未确认（有光感的机型在亮度条下面有一个）。

**文石**：从右上角下拉出控制中心：Wi-Fi、蓝牙、飞行、截图、整屏刷新等开关，音量 / 亮度 / 色温滑条；
“E-Ink 中心”里选刷新模式（HD / 平衡 / 快速 / 极速），只对当前应用生效 [LEAF2][EW35]。

**我们**（已做，`Panel.java`）：
- 一张固定半屏高的面板。第一屏只有：一排圆形开关（Wi-Fi、蓝牙（有才显示）、反色、清残影、全部设置；设置里仍可自己挑 3–6 个，键 `quick` 不变，默认值改成这五个）、
  亮度条、色温条（两端的小 / 大图标就是 − / +；有光感的机型在亮度条右边多一个“自动”复选框）。
  Kindle 的“同步”换成“清残影”：我们没有云同步，而清残影是墨水屏上最常按的一个。Kindle 的“飞行模式”写成“Wi-Fi”：宿主只有 Wi-Fi 开关，名字照实写。
- 墨水屏特有的（刷新方式、整屏刷新间隔、应用字号、对比度、翻页动画、当前应用的显示效果）收在“显示”一行后面——这是文石 E-Ink 中心的位置和内容；
  传书、自动休眠、桌面、切换应用、截图、清理后台、回 Kindle、关机收在“更多”后面；通知在右上角的铃铛里。这三页在面板里原地换内容，面板大小不变。
- **面板不再是 Activity，而是一个悬浮窗口**（和状态栏那条一样直接加到 WindowManager，类型高一层）。原来每次打开都要“暂停下面的应用 → 切任务 → 恢复面板 → 建窗口”，
  关掉时下面的应用还要被恢复一次。现在窗口一直挂着，打开只是设成可见、按宿主状态文件核对一遍；下面的应用不知道面板来过，主页也不会因为面板关掉而多刷一块。
- 打开面板本身不写任何设置（模拟器里核对过：打开、换页、关闭前后 `settings` 文件的校验和不变）。
- 点面板下面的任何地方、点右上的收起箭头、返回键、再做一次下拉手势，都是收起。

## 4. 设置

**Kindle**：一页分类列表，每项点进去是子页面。旧版分类：您的账户、家庭、Wi-Fi 与蓝牙、设备选项、阅读选项、语言与词典、辅助功能、家长控制、法律 [K5]；
新版：账户、Wi-Fi 与蓝牙、设备选项、屏幕与亮度、辅助功能、主页与书库、帮助、法律 [PW]。设置页右上三点菜单：更新、设备信息、重启、恢复出厂 [PW][TER]。
子页面“返回箭头 + 标题”的写法未在文档里确认，实机是这样。

**文石**：设置是功能栏里的一个标签，也是分类列表；手势、导航球、每应用优化各有子页 [LEAF2]。

**我们**（已做）：一页分类列表（Wi-Fi 与蓝牙 / 显示与刷新 / 手势 / 应用与桌面 / 传书 / 设备与更新 / 关于），每项一行：图标、名称、一句说明、右边一个 ›；
点进去是“‹ 标题”的子页面。返回：子页面 → 分类列表 → 主页。分类列表右上角有菜单（检查更新、设备信息、重启、回 Kindle、关机），对应 Kindle 设置页的三点菜单。
原来五个标签里的每个选项都还在，偏好键和宿主设置键一个没改，只是换了归属：

| 分类 | 内容 |
|---|---|
| Wi-Fi 与蓝牙 | Wi-Fi 开关、已保存的网络、蓝牙 / 翻页器（有蓝牙才有）、DNS |
| 显示与刷新 | 系统字体、导入字体、文字与图标大小；刷新方式、滑动刷新合并、整屏刷新、换页后整屏刷新、立即整屏刷新；翻页动画、动画速度；对比度、灰度抖动、反色 |
| 手势 | 导航方式、手势总开关、各个单独的手势、边缘灵敏度、四角长按 |
| 应用与桌面 | 每行应用数、应用排序、软件商店；壁纸深浅、桌面标题、12 小时制、状态栏；面板名称、面板快捷按钮；输入法 |
| 传书 | 开关、地址和 PIN、自动关闭时间、打开单独的传书页面 |
| 设备与更新 | 绑定账号、检查系统更新；回 Kindle 的方式、使用统计、重启；保存 / 上传日志；恢复默认、卸载 |
| 关于 | 版本、内存、问题反馈 |

长的子页面一页一页翻：在列表上划一下或点底下的箭头，抬手时翻一次，停在条目的边上（不会把一条切成两半）；底下显示“第几页 / 共几页”。
以前手指拖着列表会跟手滚动，一路连着刷。所有页面的控件树都缓存，主页闲下来时逐页预先搭好。灰色的小标题、分隔线、说明文字全部改成黑色。

## 5. 阅读器

**Kindle**：点屏幕顶部出工具栏：返回、Aa、转到（目录 / 笔记）、书签、搜索、三点 [PW][TER]。Aa 面板从下半屏出来，四个标签：主题、字体、版式、更多 [TER-Aa]。
左下角进度可以选：位置、页码、本章剩余时间、全书剩余时间、不显示 [PW]。点按区域：左边一条 = 上一页，其余 = 下一页，顶部 = 工具栏；也可以左右划 [PW][K5]。

**我们**（已做）：
- 点屏幕最上面一条（高度的 14%）出工具栏：返回、书名、Aa、转到、书签；同时底部出一条：上一页、位置、下一页。工具栏是**盖在正文上面**的一层，
  出不出工具栏正文都不重排（以前工具栏把正文往下挤，文字区变矮）。工具栏开着时点正文任何地方是收起它。
- 左边四分之一点按 = 上一页，其余 = 下一页；往左划 = 下一页，往右划 = 上一页（抬手时翻一次）。
- 页脚一直在：左边“本章还剩 N 页”（这次读了 5 页以上以后，按这次的速度加一句“约 M 分钟”），右边“第几页 / 共几页 · 百分比”。
  没有照 Kindle 做“位置（Loc）”：我们的分页是按屏幕排的，页码就是位置。
- 转到：目录、书签列表、开头、10 / 25 / 50 / 75 / 90%。书签：点一下加上（图标变黑底），再点一下去掉；存在 `reader` 偏好的 `bm:<路径>`，按“章 + 字符位置”记，改字号后还在同一段文字上。
- Aa 面板原来就是从下半屏出来的一张，保留（字体、字号、行距、边距、对齐），没有拆成 Kindle 的四个标签。
- 分页引擎没动，只把正文下面留给页脚的空白从 10dp 改成 30dp（原来页码小字会压在最后一行的右下角）。
- 打开书是一帧：窗口在第一页的字排好之前不画（最多等 3 秒），续读的书先只排上次停下的那一页（TXT 从记下的字符位置排一页；EPUB 只读那一章，
  文件名存在 `e:<路径>`），页码和“本章还剩几页”用上次存下的（排版条件 `st:<路径>` 一样时），整本分页在后台做完再对上，屏幕不动。
  第一次打开的书等分页最多 0.3 秒让页码一起出来，等不到就先出字、页码稍后补上。分页没做完时也能往后翻（从这一页末尾接着排）。PDF 第一页同样等图渲染好再画。

## 没有照搬的

| Kindle / 文石有 | 我们不做 | 原因 |
|---|---|---|
| 主页推荐位、商店按钮 | 换成应用网格和快捷设置 | 没有商店内容；应用是这个系统的主要用途 |
| 底栏中间的“当前书”图标、主页“继续阅读” | 不做 | 用户要求主页只放应用；书在书库里，点书接着读 |
| 书库右侧可拖动的滚动条 | 用页码 + 划动 | 拖动要连续刷新 |
| 收藏夹、系列分组 | 暂不做 | 需要新的数据结构，先把排布做对 |
| 封面上的“已下载”对勾 | 不做 | 我们的书都在本机 |
| 面板里的“同步” | 换成“清残影” | 没有云同步 |
| 文石导航球 | 不做 | 之前做过悬浮球，用户要求去掉了 |
